# Siryan Healthcare Management System - QA Deliverables

QA and testing deliverables for **Siryan**, a healthcare management system built as a graduation project at DigiLians (MCIT, 2026). I owned the quality assurance track: manual testing, API testing, and test documentation.

## What I Did

- Designed and executed manual test cases for the Patient, Doctor, Admin, Login, and Registration modules
- Performed API testing using Postman
- Automated UI test scripts using Selenium WebDriver
- Documented and reported defects with reproduction steps, expected vs actual results, severity, and priority
- Produced the test closure report for the QA track
